# 🚀 Saeem Chauhan — Developer Portfolio

A modern, responsive, and dark-themed developer portfolio built with React to showcase my projects, technical skills, education, internships, and professional experience.

## ✨ Features

* **Sleek Dark Theme:** Modern, clean, and developer-focused UI.
* **Smooth Animations:** Powered by Framer Motion for fluid transitions and interactive elements.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop devices.
* **Centralized Data Management:** Portfolio content such as bio, skills, projects, experience, and social links is managed through a single configuration file (`src/data/profile.js`).
* **Interactive Project Showcase:** Includes direct links to live projects and GitHub repositories.
* **Resume Download:** Provides an option to view or download my resume directly from the portfolio.
* **Reusable Components:** Built using modular React components for maintainability and scalability.
* **Modern Development Stack:** Uses React 19, Vite, Tailwind CSS v4, and Framer Motion.

## 🛠️ Tech Stack

* **Frontend:** React 19, Vite
* **Styling:** Tailwind CSS v4
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## 💻 Running Locally

To run the portfolio locally, make sure you have **Node.js** and **npm** installed.

### 1. Clone the repository

```bash
git clone https://github.com/chauhanmdsaeem/saeem-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd saeem-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📄 Customization

Portfolio information is centralized in:

```text
src/data/profile.js
```

You can update the following information from this file:

* Personal information
* Professional summary
* Technical skills
* Projects
* Education
* Internships/experience
* GitHub profile
* LinkedIn profile
* Resume link
* Social media links

This makes it easy to update the portfolio without modifying individual components.

## 🌐 Deployment

After pushing changes to GitHub, the project can be connected to Vercel for automatic deployments whenever new changes are pushed to the repository.
